🏦 Python Banking System

A beginner-friendly Banking System developed using Python and Object-Oriented Programming (OOP).

🚀 Features

- Create Bank Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- View Transaction History

🧠 OOP Concepts

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

🛠️ Technologies Used

- Python 3
- Google Colab

📂 Project Files

- Python-Banking-System.ipynb
- class_diagram.md
- README.md

🎯 Objective

To understand and implement Object-Oriented Programming concepts through a simple banking application.
